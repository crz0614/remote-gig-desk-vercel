# Remote Gig Desk Browser Agent

1. Download and extract `browser-agent-extension.zip`.
2. Open `chrome://extensions` and enable Developer mode.
3. Remove the old unpacked Remote Gig Desk Browser Agent if present.
4. Choose **Load unpacked** and select the extracted folder.
5. Open the extension, paste the one-time pairing token from Remote Gig Desk, and save.

The extension never uploads passwords, cookies, MFA codes, or CAPTCHA answers. It reports only task state, platform-session verification, extension version, and official submission evidence.
